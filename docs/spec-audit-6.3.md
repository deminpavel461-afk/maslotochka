## Расхождения и открытые заглушки

### Контент-заглушки (заложены спекой)

1. **Цены** (3.4) — заглушки до согласования прайса.
2. **Адреса точек** (3.6) — пр. Энергетиков / Московский пр. — заменить на реальные.
3. **Телефон** `+7 (812) XXX-XX-XX` — везде плейсхолдер.
4. **Юрданные** (3.9) — ИП/ООО, ИНН, адрес «уточнить у клиента».
5. **Отзывы** (3.7) — слоты без реальных текстов (так и должно быть).
6. **Фото** hero / оборудование — WebP-плейсхолдеры, не съёмка бокса/мастера/канистр.
7. **Тексты** политики и оферты — заглушки до юридической редакции.

### Отличия реализации от буквы спеки

8. **3.3 пунктуация** — в спеке пункты с точкой в конце кавычек; в UI точек нет. Смысл тот же.
9. **3.5 время этапа** — в спеке длительности не заданы; в UI стоят ориентиры `2 / 5–10 / 15–20 / 5 мин` (нужно подтверждение владельцем).
10. **3.6 Telegram** — ссылка-заглушка `https://t.me/maslotochka`, не подтверждённый аккаунт.
11. **§1 «CTA во всех секциях»** — `data-cta` только в шапке, Hero, ценах и форме. В преимуществах / таймлайне / локациях / доверии отдельных CTA нет. По §2 допустимые значения только `hero|price|form|map` — формально закрыто, по §1 можно добавить ещё кнопки записи.
12. **og:image** — относительный путь `/og.webp`; для шеринга в проде нужен абсолютный URL домена.
13. **§4 endpoint на PHP** — живой PHP runtime на машине разработки не поднят; контракт прогнан twin-скриптом + аудитом `booking.php` (задача 6.1). Перед продом повторить `acceptance-booking.ps1` на реальном PHP.
